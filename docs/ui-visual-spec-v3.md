# Pi Dashboard 视觉规范 v3 —— 细节修正包（delta）

> 2026-07-31，基于用户对新视觉的 9 条反馈 + 架构师截图/像素/单测核实。
> 本文档是 v2（`ui-visual-language-spec.md`）的**修订包**：未提及的部分维持 v2 不变。
> 所有数值为定案。改动范围：`config.rs` / `render.rs` / `label.rs` / `monitor.rs`，零新增 crate，性能预算不变。

## v3-1. `fill_triangle` 方向修复（bug）

- `render.rs` 中 `half = half_w * (1.0 - ratio)` 写反，导致 `up=true` 实际画尖朝下的三角形。**改为 `half_w * ratio`**。
- 新增方向单测：up 三角形顶行窄、底行宽；down 相反（断言首行像素数 < 末行像素数）。

## v3-2. Hero 卡文字垂直居中（观察 1）

卡 h=40 不变。内容块 = 标签盒 13 + 间距 3 + 值盒 18 = 34，上下各留 3：

- 标签：`y+3`（原 y+8）
- 值：`y+19`（原 y+23，原值底部溢出卡片 1px 的问题一并消除）
- 水平**保持左对齐 x+10**：三张卡的值形成统一垂直轴线，比各自居中更整齐（架构师决策，用户已表示水平方向无大问题）。

## v3-3. 温度趋势控件重做（观察 2）

- **尺寸**：三角形 10×9（原 8×6 太小）；平稳态横杠 10×3。
- **垂直对齐**：三角形中心对准值的光学中线：`cy = value_top + 9`（16px Medium），不要对 baseline。
- **原子化（治"撕裂"）**：温度值 + 箭头 + 报警 `!` 合并为一个 `TempValue` 组合控件——单一 bbox = 值 ∪ 箭头 ∪ `!`；任何一项变化都整体擦除（PANEL）整体重绘、只标一个脏区；全部在同一 1 Hz 节拍内完成。值、箭头、`!` 之间不允许出现跨帧中间态。
- 箭头 x = 值文本右缘 + 4；`!` 在箭头右 4。
- 配色不变：升 `TREND_HOT #f85149`、降 `COOL #58a6ff`、平稳 GRAY（"红蓝反"实为 v3-1 的方向 bug，颜色映射不动）。

## v3-6. CPU 条填充内缩（观察 9，从设计上根除）

放弃"填充与轨道同外缘"的嵌套圆角方案，改为**轨道即框、填充内缩 1px**：

```rust
// 轨道照旧
fill_rounded_rect(fb, x, y, w, h, 5, ACCENT);
// 填充内缩 1px，任何情况下都不可能越出轨道外缘
if fw > 2 { fill_rounded_rect(fb, x + 1, y + 1, fw - 2, h - 2, 4, color); }
```

- 新增像素级单测：`fw=19` 时断言 (a) 填充像素不超出 `x+1..x+w-1`；(b) 轨道左缘轮廓行（inset 5/2/1）不被填充覆盖；(c) 左右圆角轮廓对称。
- 部署后截图目检四条 CPU 条（0% / 13% / 58% / 100% 各档）。
